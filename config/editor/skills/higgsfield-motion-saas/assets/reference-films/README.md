# Reference films (read, don't run)
Sources of three delivered launch films, kept so a new film can start from code that already passed the client.
They are not runnable here (their generated images / fonts / paths are not included). Map of what to read: `references/code-engine.md` §12.
- `blip/` — BLIP. (pets with LED faces), Canvas2D, the client's quality bar.
- `lo/` — LO. (birth of the internet, "inside the system"), Canvas2D + WebGL lens, glyph kit, full synth score.
- `strata/` — Strata 2.0 (Figma-like tool), DOM engine v4 with object-carry transitions and a flooding background, plus its per-cut SPEC.
