# نهج علي في App Store و Google Play

التطبيق في `mobile/` (Capacitor): يفتح الموقع nahjali.vercel.app داخل تطبيق حقيقي، فكل تحديث للموقع يوصل التطبيق
على طول بدون رفع نسخة جديدة. يبني التطبيقين تلقائيًا `.github/workflows/mobile.yml`.

## ٢) أسرار GitHub (Settings ← Secrets and variables ← Actions ← New repository secret)

### أندرويد
| الاسم | وش هو |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | ملف مفتاح الرفع (upload key) بصيغة base64 |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة سر الملف |
| `ANDROID_KEY_ALIAS` | `upload` |
| `ANDROID_KEY_PASSWORD` | كلمة سر المفتاح |
| `PLAY_SERVICE_ACCOUNT_JSON` | (اختياري، بعد أول رفع يدوي) حساب خدمة من Google Cloud له صلاحية «Release manager» في Play Console، عشان الرفع يصير تلقائي |

### آيفون (TestFlight والمتجر) وبرنامج الماك
| الاسم | وش هو |
|---|---|
| `APPLE_TEAM_ID` | رقم الفريق (Membership details في developer.apple.com) |
| `ASC_KEY_ID` و `ASC_ISSUER_ID` | من App Store Connect ← Users and Access ← Integrations ← App Store Connect API ← مفتاح بصلاحية App Manager |
| `ASC_KEY_P8_BASE64` | ملف المفتاح ‎.p8 بصيغة base64 |
| `MAC_CERT_P12_BASE64` و `MAC_CERT_PASSWORD` | شهادة «Developer ID Application» (لبرنامج الماك بدون تحذير) |
| `APPLE_ID` و `APPLE_APP_SPECIFIC_PASSWORD` | إيميل حساب أبل وكلمة سر خاصة بالتطبيقات من appleid.apple.com |

## ٣) قبل أول رفع

**أبل**
1. App Store Connect ← Apps ← ＋ ← iOS، الاسم «نهج علي»، Bundle ID ‏`app.nahjali.app`، اللغة الأساسية العربية.
2. **تسجيل الدخول باستخدام Apple** (المتجر يشترطه لأن فيه دخول بقوقل): في developer.apple.com سوّ Services ID ومفتاح
   Sign in with Apple، وبعدين في Supabase ← Authentication ← Providers ← Apple فعّله وحط القيم. الزر يطلع في صفحات الدخول
   لحاله أول ما يتفعّل.
3. بعد ما تضيف الأسرار، كل دمج في main يرفع نسخة لـ TestFlight. جرّبها، وبعدين «Add for Review».

**قوقل**
1. Play Console ← Create app، الاسم «نهج علي»، تطبيق، مجاني.
2. أول نسخة ترفعها بنفسك: نزّل `NahjAli.aab` من صفحة الـ Actions (Artifacts) وارفعه في Testing ← Closed testing.
3. الحسابات الشخصية الجديدة: اختبار مغلق مع **١٢ شخص لمدة ١٤ يوم** قبل طلب النشر للعامة.

## ٤) نص المتجر

**الاسم:** نهج علي
**العنوان الفرعي (Apple، ٣٠ حرف):** كتيبات وفيديوهات بالذكاء
**الوصف القصير (Google، ٨٠ حرف):** كتيبات عادات لطفلك بشخصيته الكرتونية، وفيديوهات ومونتاج بالذكاء الاصطناعي.

**الوصف:**
نهج علي منصة عائلية بالعربي:
• كتيب نهج علي: ارفع صورة طفلك ونحوّلها لشخصية كرتونية تتعلّم الصلاة والقرآن والعادات الطيبة في كتيب ملوّن باسمه.
• الجواد الذكي: اصنع صور وفيديوهات وأصوات بالذكاء الاصطناعي من وصف بسيط.
• الطالب الذكي: مساعد للدراسة يلخّص ويشرح ويختبر.
• حيدرة كت: مونتاج فيديو سهل من الجوال، مع مساعدك حيدرة اللي يقص ويرتّب ويضيف النصوص والموسيقى بكلامك.
احفظ أعمالك وشاركها مباشرة على واتساب وإنستقرام وتيك توك.

**الكلمات المفتاحية (Apple):** كتيب,أطفال,عادات,مونتاج,فيديو,ذكاء اصطناعي,قرآن,صلاة,تعليم,كرتون
**الفئة:** التعليم (الثانوية: الصور والفيديو). **لا تختار قسم الأطفال (Kids)**: التطبيق يستخدمه ولي الأمر.
**العمر:** ‎4+ (Apple) / ‎Everyone (Google)، مع الإشارة إن فيه محتوى يولّده المستخدم بالذكاء الاصطناعي.
**رابط الخصوصية:** https://nahjali.vercel.app/privacy
**رابط الشروط:** https://nahjali.vercel.app/terms
**رابط الدعم:** https://nahjali.vercel.app
**حذف الحساب (Apple و Google يطلبونه):** https://nahjali.vercel.app/account/delete
